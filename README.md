# To-do List do Aluno Senac EAD

Projeto Integrador desenvolvido para auxiliar estudantes na organização de tarefas, atividades e prazos acadêmicos.

## Objetivo

Criar uma aplicação simples e funcional que permita o acompanhamento de tarefas e marcos acadêmicos, como provas, quizzes, PTI e Projeto Integrador.

## Funcionalidades planejadas

- Cadastrar marcos acadêmicos
- Consultar marcos acadêmicos
- Alterar marcos acadêmicos
- Cadastrar tarefas
- Consultar tarefas
- Excluir tarefas
- Marcar tarefas como concluídas

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Estrutura do projeto

- `index.html`: estrutura principal da aplicação
- `css/style.css`: estilos visuais
- `js/script.js`: funcionalidades da aplicação
